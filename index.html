🗂️ Dataset

2026 Stack Overflow Annual Developer Survey. 13,507 respondents filtered to 12,557 employed and freelance developers. 80/20 stratified train/test split. Target: ConvertedCompYearlyBucket (15 ordered salary classes from $0–$10k to >$500k).

🔧 Feature Engineering

Country_tenc — target-encoded country (mean salary bucket per country, fitted on training data only); explains 46% of salary variance. SeniorityIndex = YearsCode × WorkExp — interaction term. TechBreadth = sum of technology counts. AIAdoptionLevel = 2 × AI tool count. has_C++, has_AWS — binary technology indicators.

📐 Model Architecture

Cumulative-threshold ordinal logistic regression (Frank & Hall, 2001). K−1=14 binary logistic regression classifiers, each asking "does this person earn more than bucket k?". Probabilities recovered as P(Y=k) = P(Y>k−1) − P(Y>k). Monotonicity enforced via np.minimum.accumulate. 38.3% of training predictions required correction.

⚙️ Hyperparameters

L2 regularisation, C=0.1 (selected by 5-fold stratified CV grid search over C ∈ {0.001–100} × {L1, L2}). Features standardised by StandardScaler fitted on training data only. Sample weights balanced across all 15 salary buckets to handle class imbalance.

📊 Performance

Test macro F1 = 0.189 (vs 0.020 majority-class baseline). Accuracy = 0.221 (vs 0.180 baseline). Mean absolute bucket error = 1.94 buckets (vs 2.46 baseline). 52.7% of test predictions within ±1 bucket. The model beats the baseline on every metric. Country_tenc was the key missing feature in the original model.

⚠️ Limitations

Country target encoding is unstable for the 45 countries with ≤5 training respondents. The model is predominantly underfitting — a linear model cannot capture country × seniority × technology interactions. Expected salary is inflated by balanced weights on rare high-salary buckets; the most likely bucket is the more reliable point estimate.
