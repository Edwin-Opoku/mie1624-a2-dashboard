🗂️ Dataset

2026 Stack Overflow Annual Developer Survey. 13,507 respondents filtered to 12,557 employed and freelance developers. 80/20 stratified train/test split. Target: ConvertedCompYearlyBucket (15 ordered salary classes from $0–$10k to >$500k).

🔧 Feature Engineering

SeniorityIndex = YearsCode × WorkExp — captures compounding seniority that a linear model cannot derive from main effects alone. TechBreadth = sum of all five technology counts. AIAdoptionLevel = 2 × AI tool count.

📐 Model Architecture

Cumulative-threshold ordinal logistic regression (Frank & Hall, 2001). K−1=14 binary logistic regression classifiers, each asking "does this person earn more than bucket k?". Probabilities recovered as P(Y=k) = P(Y>k−1) − P(Y>k). Monotonicity enforced via np.minimum.accumulate.

⚙️ Hyperparameters

L2 regularisation, C=0.1 (selected by 5-fold stratified CV grid search). Features standardised by StandardScaler fitted on training data only. Sample weights balanced across all 15 salary buckets to handle class imbalance.

📊 Performance

Test macro F1 = 0.099 (vs 0.020 for majority-class baseline). Accuracy = 0.118 (vs 0.180 baseline). Mean absolute bucket error = 3.14. The model substantially outperforms the baseline on class-sensitive metrics but underfits — a linear model on 17 survey features is too simple to separate 15 narrow salary bands precisely.

⚠️ Limitations

No country feature (a major salary determinant). Multi-select technology columns compressed into counts (losing which technologies). The 15 salary bands are only 10–25k wide each — finer than the features can resolve. Expected salary is inflated by balanced weights on rare high-salary buckets.
